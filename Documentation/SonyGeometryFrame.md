# Sony 几何映射的显式坐标契约

`Sources/Native/LensSonyGeometry.h` 提供后向采样坐标计算。它仍是厂家表接入前的算法基础，**未被产品渲染器调用，也没有新增自动镜头支持**。调用方必须明确给出校准空间、解码区域、显示方向和输出尺寸；本模块不会从 `FullImageSize`、存储尺寸或 Core Image 尺寸中猜一套厂家校准坐标。

## 输入及方向

`LensSonyExplicitPixelFrame` 的四项含义：

| 字段 | 坐标含义 |
| --- | --- |
| `calibrationSize` | 调用方明确提供的未旋转校准空间尺寸。中心为宽、高的一半，归一化半径以半对角线为单位；这只是算法约定，不证明 Sony 使用这套空间 |
| `decodedRegion` | 解码画面在校准空间中的未旋转裁切矩形，必须完整位于校准范围内 |
| `orientation` | EXIF 1–8，包含反射；先对裁切区域应用方向，再缩放到输出尺寸 |
| `outputSize` | 方向处理后的显示像素尺寸。可表示预览缩放或分别调整横纵尺寸 |

所有坐标均为局部左上原点，像素中心为 `(0.5, 0.5)`，不把首像素索引 `(0, 0)` 当作像素中心。Core Image 的图像空间使用下方原点；未来接入时必须明确转换局部 Y 和 extent 原点。位图内存的首行与 Core Image 图像空间也不能混为一谈：测试通过原生区域采样单独核查了这一区别。

`LensSonyPrepareGeometry` 校验来源表、空间范围和强度，把表及两个方向变换准备成 528 字节的值结构。畸变和色差强度分别为 0–2，0 表示关闭；只要求开启的分量存在。两项同时使用时分别插值、调整倍率，再相乘，沿用已验证的标量约定。绿色仍是色差参考通道。

`LensSonyMapGeometryPoint` 接收目标显示坐标，逆变换回校准空间计算半径及通道倍率，再将采样点变回显示空间。它不夹紧出界采样点：边缘约束必须由后续裁切步骤处理，夹紧会把缺失边缘拉成条带。没有默认畸变，也没有暗角增益。零表或关闭后直接返回原坐标，避免仿射往返造成的微小误差引入额外重采样。

非法尺寸、越界裁切、未知方向/通道、不支持的来源、缺失请求表、冲突节点数、非有限参数和非正倍率会拒绝。失败的准备结果清零；失败的映射结果返回非有限坐标，不留下上次成功结果供调用方误用。

## 已验证范围

`Tests/make-sony-pixel-frame-reference.py` 用 60 位 Decimal 计算和独立的显式方向矩阵，生成三个数学空间中的目标/采样点对。它从已知校准坐标构造显示坐标；原生实现则从显示坐标求逆，因此没有直接用被测逆变换生成期望值。

`Tests/verify-sony-pixel-frame.m` 验证：

- 2016 个 Decimal 参照点：八种方向、整幅/偏移裁切、非等比缩放、三通道、0–200% 的七组强度组合；最大二维误差约 `2.55e-13` 像素。
- 144 个零表或关闭案例严格返回输入坐标；33 个无效输入拒绝。
- 2–16 节点共 1665 个采样与现有标量核心一致，包含端点延拓；最大二维差约 `2.85e-14` 像素。
- Core Image 实际 `imageByApplyingOrientation` 结果：16 张内存坐标图、245760 像素，最大校准坐标误差约 `3.82e-6` 像素。仅应用方向，没有应用光学校正表。
- 在本机单次标量循环中，20 万点准备后计算约 2.8 ms，逐点解析字典的标量路径约 170 ms；结构占 528 字节。这是开发数值基准，**不能宣称 Pixelmator 应用、预览或导出加速同样倍数**。

运行常规 `python3 Scripts/test.py` 会包含本测试。单独编译时使用与常规测试相同的 Cocoa、CoreImage、ImageIO 框架。证据为 `Evidence/sony-explicit-pixel-frame-verification.json`。

32 个常规组和 192 组既有原生渲染回归通过；随后仅在这份新测试中增加原生方向与全部节点数量检查，并单独编译运行最终测试通过。两次范围分别记录，不把早先的全套日志当作后来新增断言的运行记录。本轮没有重建产品、更新研究宿主或生成 DMG。

## 接入前仍缺的证据

这套数学坐标映射不能自行确认厂家标定的空间、中心或后向采样约定。此前 A6000 的解码器图像配准只证明本次解码器间的裁切关系。将来启用时还需用独立实际图像确定校准空间，绑定到本次 RAW，保持原生优先，并为该表使用真实的提供者类型；不能用假造 Lensfun 多项式绕过校准检查。

还需验证实际后向采样、约束边缘、可编辑保存/重开、图层已有变换、旧文档兼容与真实宿主图像结果。厂家暗角的光学响应仍单独待验；本模块没有从场景亮度生成任何提亮曲线。完整 Lightroom 等量覆盖尚未实现。
