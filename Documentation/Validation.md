## 实际渲染与历史核查

`Evidence/host-render-history-verification.json` 记录一张 Nikon NEF 在真实隔离宿主中的畸变倍率 100% → 50% → 面板撤销 100% → 面板重做 50%。每次保存后只读提取 PXD 的 `QuickLook/Preview.heic`，均为 2000 × 3008；半强度改变了预览像素，撤销与重做分别逐像素等于相应参考预览，内嵌 RAW 哈希与手选标识不变。该 HEIC 预览是宿主渲染证据，不能替代无损 PNG 导出或证明光学准确性。最初基准 PNG 导出成功，后续导出按钮被禁用，未完成同格式 PNG 比较。新模块重启后的打开按钮也被禁用，尚未完成这一轮保存文件的界面重开验证。

`Tests/compare-rendered-images.m` 是只读核查工具，将两张导出图或保存预览统一解码为预乘 8 位 sRGB RGBA，再比较尺寸、像素哈希及差值。相同图、单像素变化和尺寸不一致三个烟雾检查已通过。它不参与用户编辑流程，不产生中转 TIFF。诊断核查范围另见 `Evidence/host-diagnostics-verification.json`。

## 可选私人 RAW 批量核查

`Tests/audit-private-raw-corpus.m` 使用生产元数据读取、原生配置生成和推荐策略；输入私人 JSON 数组，每项为原片路径，或 `{ "path": "…", "expectedFocalMM": 104, "expectedApertureAPEX": 4.970854 }`。带参考值时逐项比较焦距与拍摄光圈；输出仅计数、相机/镜头汇总和失败索引。不要把输入清单或照片提交到仓库。它不修改目录或照片，不渲染完整照片，也不测量光学误差。

本轮 821 张全部带独立目录参考值运行通过；汇总和源码/二进制哈希在 `Evidence/private-raw-corpus-verification.json`。该修复模块已在隔离宿主退出后替换、保留沙盒重新签名并启动；仍因选中文档后 Open 灰色而未完成新版重开界面验收。现有发布资产未更新。

## 完整 LX3 原片与文件面板控制

两份公开 CC0 LX3 RAW（1:1 与 4:3）已通过原片 SHA256、原始传感器模式、自动焦距/光圈、对应相机配置、实际 Core Image 预览渲染、原生优先和原片不变检查。十八组测试及 96 个原生渲染组合通过，见 `Evidence/public-lx3-verification.json`。这补充了真实 RAW 证据，尚不覆盖 Pixelmator GUI、光学误差或完整保存/重开。

## 0.2.1 自动参数与实际重开

用户随后确认原厂应用手动打开、编辑、保存正常。CUA 使用正常键盘选择后，原厂应用 Open 可用且完整载入 A6000 RAW；研究宿主也实际完成打开、首次保存、关闭和最近文档重开。旧文件面板失败仍是历史证据，不能再作为当前应用无法保存的结论；底层自动操作差异尚未作隔离根因证明。

三份完整公开 Sony/Olympus RAW 的拍摄参数对照通过，前两份可自动生成镜头配置；A200 镜头未唯一匹配，明确单列。源图不进入源码包。十九组测试与 96 个原生渲染组合通过，详见 `Evidence/public-capture-metadata-verification.json`。

实际 A6000 PXD 已核对原 RAW 的 25,624,576 字节及 SHA256 不变，保存的三项开关为开启畸变、开启色差、关闭暗角。重开时宿主将白平衡派生 cx/cy 重算了约 6–7 个 float ULP，导致旧版严格字典比较误判。修复只在主色温、色调、白平衡模式及其余状态完全相同的前提下，为这两个有效派生坐标容许有限 float 舍入；所有其他绑定字段仍精确比较。旧回归退出 11，修复后通过，修改主白平衡/原生开关/强度/明显坐标变化仍拒绝。退出研究宿主后更新模块、保留沙盒重新签名并重启，同一 PXD 无需点击重新匹配便恢复面板、自动参数和三项选择，见 `Evidence/a6000-reopen-verification.json`。没有改写该原保存文件。

该测试同时暴露明确性能限制：24 MP PXD 为 1,374,741,605 字节，效果档案约 1.34 GB；CPU 采样主要在全尺寸映射 LZFSE 压缩。0.2.1 未优化该问题，后续 0.2.2 结果见下节。旧版资产保留。

## 0.2.2 紧凑映射、实际保存与导出

临时工作映射避免先压缩、再解压全尺寸浮点表；随后逐个全分辨率坐标检查像素位移网格，必要时附带 RG8 残差。误差上限为 0.001 px，无法满足则保留密集格式。暗角增益独立检查上限 0.00001，网格数据再作逐位无损编码；不能把网格近似称为逐位无损。八种 EXIF 方向的七个几何平面及增益，工作路径与密集路径逐点比较均通过。

21 组自动测试、192 个原生渲染组合通过。残差测试使用块状坐标扰动和高频源，逐组与同设置密集渲染比较；预算来自密集渲染 CPU 参考误差、坐标误差上限、强度权重和源梯度。故意去掉残差项后退出 7，配对误差 0.0117188 超过推导预算 0.000954556，证明该回归可以抓到漏用残差。16 位 PNG 比较工具另有相同图、单通道 1/65535 变化及尺寸不符自检，不先降至 8 位。

同一 A6000 6000×4000 PXD 副本经实际界面保存、关闭、重新打开：97,602,164 字节，相对旧密集测试的 1,374,741,605 字节减少约 92.9%。原 RAW 为 25,624,576 字节，SHA256 不变；RAW 图层、镜头效果、畸变/色差开启、暗角关闭及倍率 100/100/50 均保留。面板自动读取 39 mm、f/5；未记录距离时明确显示 1000 m 远距回退。打开面板会重新读取建议并保留三项选择；新建议尚未应用的文案不表示已有图层效果消失。

迁移过程中，宿主自动保存已更新原来的自有基准 PXD；它不再是旧格式原档，不能用于声称“旧 PXD 未改”。旧版 16 位 PNG 在更新模块前已实际导出并保留。新旧导出均为原尺寸、16 位 Display P3、相同 ICC；平均绝对 RGB 通道差为 0.720109944 / 65535，99% 为 15 / 65535，99.9% 为 32 / 65535，最大为 209 / 65535，alpha 无变化。该结果说明实际渲染存在差异，不是逐像素相等或光学等效证明。

独立配置生成基准约 10.101 秒、进程峰值内存 2,267,906,048 字节；不包含 GUI 提交、旧文档迁移、历史、保存或导出。该样本逐坐标最大误差约 0.00075 px，增益误差约 0.000005508。未测 8 GB Mac、第二台设备、所有 RAW 或长期性能；当前几何生成仍限制在 48 MP。

冻结的 0.2.1 渲染代码遇到新格式标记会保留原输入和不透明档案，避免误解位移坐标；没有完成旧宿主的完整界面验收。新版校正需 0.2.2 或更新宿主显示。临时目录中的 0.2.2 完整安装、模块及宿主严格签名、已安装识别和原厂关键字节复验通过，不替换用户安装。源码、模块、测试日志哈希及各项范围见 `Evidence/compact-map-verification.json`。

## 0.2.3 开发候选：几何边界

0.2.2 的实际导出与更新前密集基准图均存在外边缘条带。旧渲染回归主动跳过内部参考无法可靠处理的边缘，因此 192 个组合通过并不覆盖此问题。新增原生效果包装器回归用独立解析平移，冻结旧渲染器在首个失败用例中有 1,024 个超出原图的采样全部仍输出颜色和不透明 alpha，退出 7。

开发修复明确将任一必要颜色通道超出原图采样范围的位置设为透明，不复制原图边缘。数值校准表在渲染内存中加一圈重复的边界节点，并限制采样索引，避免 GPU 在表边缘混入零值；原片像素与标定数值不改写。普通 clamped 图像/采样器的实验因改变内部映射未采用。

288 个组合覆盖四个平移方向、畸变/色差独立与联合、关闭及部分/完整/超完整强度、两种传递函数，以及密集/位移网格/残差网格。935,832 个明确越界采样全部透明，有效内部最大通道误差约 0.0000018。另有 8 个非对称暗角增益组合，检查全画布及所有边角，不跳过外边缘。48 个裁切区域与整图参考的最大差为零。当前 23 个常规组、既有 192 个渲染组合与构建通过；第 24 个全尺寸组在默认套件中明确跳过，并已另行显式执行通过。证据见 `Evidence/geometry-boundaries-verification.json`。

完整尺寸检查暴露了直接创建带边界整张 bitmap 的内存负担：两次 CLI 专项分别在观察到约 5.6 GiB 和 8 GiB RSS 后以 137 退出，尚未证明终止根因；手工合成多块的两个方案在 Metal 渲染阶段退出 134，均未采用。最终使用不可变 `CIImageProvider`、准确 ROI、`samplerTransform`、按需平面解码和 macOS 26 公开 tiled intermediate。2050×1030 非对称有符号数值场、bitmap 对照及 tiled 路径逐值相等；两个故意忽略 samplerTransform 的负对照误差约 0.699。A8 输出也已验证，见 `Evidence/calibration-image-verification.json`。

6000×4000 专项从固定公开 A6000 RAW 自动读取 39 mm、f/5 并生成实际校准映射，经效果编码往返和原生包装器渲染，用独立 CPU 字段解码检查三组未裁切强度。总计 72,000,000 个位置，其中 5,507 个处于预声明的 0.05 px 分类排除带；1,830,385 个明确越界位置全部透明，明确有效内部全部不透明。该排除带仅用于 GPU alpha 的边界分类，不改变 0.001 px 映射压缩误差预算。源图为不透明常量，**不是解码照片或光学准确率测试**。

## 0.2.3 build 7：可逆约束边缘

用户在实际照片看到透明空边后，新增独立的“约束边缘 · 自动裁切”选项。算法对当前实际标定字段的全部节点和残差求保守位移区间，包含超过 100% 时的负权重和所有必要颜色通道，再计算保持比例的居中裁切，并预留 2 个原图像素。裁切映射合入几何采样，不在校正后再做一次图像重采样；不拉伸边缘、不生成照片内容、不提高曝光。视角会缩小，原画布大小和完整 RAW 保留。没有几何补偿时保持原样；旧文档缺少该项时保留原构图，新自动建议开启此项，可手动关闭。
