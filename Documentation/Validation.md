# 预览验收记录

截至 2026-10-15，交付状态为预览版；完整目标仍未达成。下表的实际界面与安装证据对应已发布的 0.1.0 预览；后续匹配源码改进尚未打入该 DMG，见 [匹配规则与开发核查](Matching.md)。

| 项目 | 当前证据与边界 |
| --- | --- |
| 原生优先策略 | 真实 R50 V CR3 面板显示原生支持，畸变/色差自动跳过，额外去暗角关闭且 0 EV，无独立标定时不能应用空效果 |
| 有效额外暗角 | 原生支持的合成路由+实际 Lensfun 标定测试：几何映射不生成，暗角可手动开启、设置可序列化；并非实拍残余暗角准确性证明 |
| RAW 保留 | 历史 Nikon PXD 保存/关闭/重开，内嵌 NEF SHA256 不变；本轮新策略重开后设置保留。没有 TIFF 中转 |
| 推荐 UI | 实际 Nikon 显示 1.155% 畸变、0.189 px 色差、0.147 EV 试用去暗角且关闭；推荐按焦距插值变化 |
| 渲染 | 密集/网格各 48 组，三项独立开关、部分/超完整倍率、两种传递函数及其他效果保留 |
| 内容边角 | 孤立暗物体、对称衰减、高光溢出测试；仍是保守启发式，不能证明所有自然内容均能可靠分离 |
| DMG 背景 | 实际 Finder 检查内嵌矢量 PDF：文字清晰、图标对齐、底部完整；移开源图并异名挂载后系统书签仍解析到镜像内部。尚未在第二台电脑测试 |
| 安装 | 本机通过 GUI 安装、从安装程序启动，新增菜单可见，签名校验通过，原厂关键文件哈希不变 |
| 文件对话框 | 本轮曾禁用打开；重启后真实 CR3 成功导入并完成新面板检查，尚未证明根因修复 |

## 尚未验收

- Lightroom Classic 等量镜头覆盖或光学等效。公共库缺项不由猜测补齐；Canon 某些嵌入校准包数值含义仍未验证。
- 身份歧义的手动候选选择器；目前停止并解释，不能伪称所有镜头自动匹配成功。
- 原生处理后残余暗角的实际测量与针对性标定；额外补偿默认为零且关闭。
- 初次保存偶发不可用、完整历史事务、多图层、裁切/变换、所有颜色空间、长期稳定性、速度和文档体积。
- 另一台 Mac、macOS 26、正式 Developer ID 签名、公证和 Gatekeeper 下载分发验证。
- 当前 CUA 截图尺寸异常，未完成全尺寸像素视觉或完整无障碍审计；实际交互主要由 AX 状态核验。

Evidence 中 JSON 是精简验证结果，各文件包含所测范围或构建哈希。测试通过不扩展为上述未测项目的保证。默认开发测试会跳过未提供的私人 RAW，真实样本证据来自已执行的本机专项验证。
