## 尚未验收

- Lightroom Classic 等量镜头覆盖或光学等效。公共库缺项不由猜测补齐；Canon 某些嵌入校准包数值含义仍未验证。
- F810 等其余拍摄模式自动解析、LX3 完整实拍的原生宿主核查及更多真实歧义 RAW。现有手选及补全参数入口不计作自动匹配成功；缺失参数流程的实际宿主保存/重开仍需补充。
- 原生处理后残余暗角的实际测量与针对性标定；额外补偿默认为零且关闭。
- 诊断代码曾按 Boolean 方法名称调用 canCloseDocument，疑似引起额外关闭提示；已改为明确 getter 允许列表，旧实现失败及新实现通过的回归已加入测试。新版实际打开面板仍禁用 Open，重开复测受阻，不能判定关闭/文件面板根因均已修复。未修改的官方应用选择普通 PNG 也实测为灰色 Open，说明该限制可在 LensDock 之外复现，尚未定位根因；见 `Evidence/vendor-open-panel-control.json`。
- 初次保存偶发不可用、完整历史事务、多图层、裁切/变换、所有颜色空间、长期稳定性、速度和文档体积。
- 另一台 Mac、macOS 26、正式 Developer ID 签名、公证和 Gatekeeper 下载分发验证。
- 本轮 CUA 已恢复正常尺寸截图，已与 AX 共同确认 Open 灰色；早前截图尺寸异常期间的实际交互主要由 AX 核验。完整视觉及无障碍审计尚未完成。

Evidence 中 JSON 是精简验证结果，各文件包含所测范围或构建哈希。测试通过不扩展为上述未测项目的保证。默认开发测试会跳过未提供的私人 RAW，真实样本证据来自已执行的本机专项验证。

## 实际渲染与历史核查

`Evidence/host-render-history-verification.json` 记录一张 Nikon NEF 在真实隔离宿主中的畸变倍率 100% → 50% → 面板撤销 100% → 面板重做 50%。每次保存后只读提取 PXD 的 `QuickLook/Preview.heic`，均为 2000 × 3008；半强度改变了预览像素，撤销与重做分别逐像素等于相应参考预览，内嵌 RAW 哈希与手选标识不变。该 HEIC 预览是宿主渲染证据，不能替代无损 PNG 导出或证明光学准确性。最初基准 PNG 导出成功，后续导出按钮被禁用，未完成同格式 PNG 比较。新模块重启后的打开按钮也被禁用，尚未完成这一轮保存文件的界面重开验证。

`Tests/compare-rendered-images.m` 是只读核查工具，将两张导出图或保存预览统一解码为预乘 8 位 sRGB RGBA，再比较尺寸、像素哈希及差值。相同图、单像素变化和尺寸不一致三个烟雾检查已通过。它不参与用户编辑流程，不产生中转 TIFF。诊断核查范围另见 `Evidence/host-diagnostics-verification.json`。

## 可选私人 RAW 批量核查

`Tests/audit-private-raw-corpus.m` 使用生产元数据读取、原生配置生成和推荐策略；输入私人 JSON 数组，每项为原片路径，或 `{ "path": "…", "expectedFocalMM": 104, "expectedApertureAPEX": 4.970854 }`。带参考值时逐项比较焦距与拍摄光圈；输出仅计数、相机/镜头汇总和失败索引。不要把输入清单或照片提交到仓库。它不修改目录或照片，不渲染完整照片，也不测量光学误差。

本轮 821 张全部带独立目录参考值运行通过；汇总和源码/二进制哈希在 `Evidence/private-raw-corpus-verification.json`。该修复模块已在隔离宿主退出后替换、保留沙盒重新签名并启动；仍因选中文档后 Open 灰色而未完成新版重开界面验收。现有发布资产未更新。
