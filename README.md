# LensDock · 镜头坞

**保留 RAW 的 Pixelmator 镜头矫正预览版（开发源码 0.2.6 build 10）。** 支持目标为 Apple 芯片 Mac、macOS 26 及以上。为原生镜头矫正尚不支持的照片，补充有可靠标定依据的畸变、横向色差和暗角补偿；原生支持时自动跳过补充畸变与色差，并保留默认关闭的“额外去暗角”。

0.2.5 build 9 改用 **Pixelmator Pro 4.3+ 通用兼容检查**：版本门槛、签名、arm64 结构、必要接口与运行时数据布局通过即可使用，不按每个 build 登记允许哈希。打开照片后自动自检并提示，首次可勾选“以后不再自动提示”；后台保护仍保留，菜单可重新检查、复制诊断并前往 [GitHub Issues](https://github.com/zhangchengzezcz/LensDock/issues)。当前实测基线为 4.3 / macOS 27.2，后续版本采用通用检查与问题反馈，不宣称逐一实测。

约束边缘已完成真实文档重开及 6000×4000、16 位 Display P3 PNG 导出核查：2400 万像素全部不透明。分数尺寸预览 alpha 与无矫正缩放对照逐字节一致。镜头库覆盖、光学精度、内存较少设备及后续版本的行为有已知边界，详见验收文档；缺可靠标定时保留原片，不猜测校正。打包版本、大小及校验和以 `Distribution/<版本>-preview/` 清单为准，历史资产保留。

0.2.5 候选包保留原样；0.2.6 开发源码补充照片延迟载入的主动重试，以及 F810 有文档依据的 RAW 标准模式路由。自动回归与隔离安装已通过，但新反射桥接、照片打开后自动提示及忽略选项仍待实际照片界面复测。完整目标与 Lightroom 等量自动匹配仍未完成，见 [完整目标验收](Documentation/Completion.md)。现有 Releases 资产对应各自的历史版本。

当前是可安装、已做本机测试的预览版。**尚未达到 Lightroom Classic 的镜头覆盖范围或光学等效验收，也不是 Apple 官方扩展。** Pixelmator 没有提供本项目所需的公开 RAW 编辑插件接口，因此安装程序从用户自己安装的兼容应用建立独立本机宿主，在其菜单与可编辑效果中集成 LensDock。原厂应用保留；分发包不包含 Pixelmator 应用或框架。

## 安装与使用

1. 在 **macOS 26 或更新版本的 Apple 芯片 Mac** 上自行安装 **Pixelmator Pro 4.3 或更新版本**。Intel 不在本项目支持范围内。
2. 打开含内嵌矢量高清背景的 DMG，将 `LensDock.app` 拖到“应用程序”，打开 LensDock。
3. 点击“安装预览宿主”。版本门槛、必要导出接口、签名与 arm64 加载结构全部通过才会安装；不需要管理员权限。
4. 点击“打开 Pixelmator”，打开 RAW 并选中 RAW 图层，进入 **镜头矫正 → 打开镜头矫正…**。
5. 照片载入后会自动显示兼容检查，可选择以后不再自动提示。查看推荐量，独立选择三项功能，点击“应用到 RAW”。重新匹配恢复本次建议；普通重新打开会重新检测支持并保留已保存的手动选择及拍摄参数覆盖。

宿主安装位置为 `~/Applications/Pixelmator LensDock Preview.app`。含 LensDock 效果的 PXD 请通过此宿主打开，原厂应用没有该自定义滤镜。原 RAW 保留在文档资源中，无 TIFF 中转。主滑块显示实际最大校正量（短边位移百分比、色差像素、暗角 EV），详细设置保留标定倍率与焦距、光圈、距离；修改参数不改写原片 EXIF。

0.2.3 开发候选新增 **约束边缘 · 自动裁切**：根据当前几何字段与强度计算保守的居中裁切范围，等比放大填满原画布，视角会缩小；它与几何矫正在同一次采样完成，完整 RAW、画布尺寸和比例保留。关闭此项并重新应用即可恢复完整视角，此时几何矫正可能留下透明空边。新匹配默认推荐开启；旧文档缺少该设置时保留原构图，需手动勾选或重新采用自动建议。此项不从照片内容猜测畸变，不增加暗角提亮；原生处理或零几何补偿时不额外裁切。

**文档版本：** 0.2.2 引入紧凑映射格式。新版可读取已有密集映射；含新格式校正的文档需要 0.2.2 或更新宿主才能显示该校正。0.2.1 渲染代码会保留输入和不透明效果档案，跳过新格式，避免误读坐标；这项旧版行为已做代码级检查，尚未完成旧宿主完整界面验收。升级前保留文档与兼容宿主。

选择“约束边缘”的效果另使用格式 5，需要 **0.2.3 build 7 或更新宿主**。旧渲染器会跳过校正并保留原片与档案；这不代表旧版本能显示同一构图，旧宿主完整界面兼容仍未验收。

**分发状态：** 当前仅 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证。已验证本机安装与启动；下载到其他 Mac 后可能受 Gatekeeper 限制，不能视为正式的一键分发版。如系统允许且用户决定运行，可使用系统设置提供的“仍要打开”流程。正式发布需要补齐签名、公证和另一台 Mac 的安装验证。构建目标为 macOS 26.0，实机验证环境为 macOS 27.2；macOS 26 尚未实测。

## 原生优先与推荐规则

“能够读取 RAW / 镜头名称”不等于“能够矫正”。本项目针对每张原片调用公开的 `CIRAWFilter.isLensCorrectionSupported` 检测矫正能力，而不是根据相机解码清单推断。

| 当前状态 | LensDock 行为 |
| --- | --- |
| 原生支持 | 补充畸变、色差自动跳过，保留原生 RAW 开关当前状态，不偷偷打开它 |
| 原生支持，另有有效暗角标定 | 显示“额外去暗角”，默认关闭、推荐 0 EV，可手动试调；不把完整标定当成已测得的残余暗角 |
| 原生支持，缺少独立暗角标定 | 保留选项和原因，但禁用补偿；没有新效果可应用时禁用“应用到 RAW” |
| 原生不支持，独立配置唯一且有效 | 使用 Lensfun 的实际标定；缺少或数学上为零的某项不生成该项补偿 |
| 不明支持状态、歧义配置、未知镜头或越界焦距 | 明确报告，停止添加补偿，不用“相似镜头”代替 |

公共原生支持标志并不提供逐项畸变/色差/暗角能力明细；跳过补充几何是本项目防止重复矫正的策略，不是逐项原生光学效果等效的证明。

对原生不支持的照片，边角内容与高光检测只能约束可靠镜头标定的补偿强度。孤立暗物体、逆光和复杂边角不能当成暗角证据；不确定时保留关闭状态，提供保守试用量或 0。无有效标定时不生成畸变、色差或提亮曲线。三个开关和用户强度分别随效果保存。

## 覆盖与验证

数据库来自 Lensfun 公共数据库提交 `43f9e001ab66c4fcdd4f400463f13b72f94b2288`，有 1057 个相机条目、1571 个镜头条目。数据库衍生的 1566 个身份/插值样本中 1537 个匹配成功，29 个因相机或镜头歧义拒绝；另有 5 个条目没有可测试标定/兼容相机。这些数字**不是实际 RAW 支持率，也不是光学准确率**。

上述数量对应已发布的 `v0.1.0-preview`。当前开发源码增加了相机地区名称、镜头与卡口联合证据、传感器校准版本选择及 XML 原始别名保留；自动目录样本匹配为 1563 / 1566。另可从 LX3 原始 RW2 边界字段确认拍摄模式。开发版面板提供可搜索的“选择配置…”：确认相机模式和镜头校准，重新计算建议，再通过“应用到 RAW”保存。实际 Nikon PXD 已验证手选配置保存、关闭和重新打开；内嵌原 RAW 不变。详见 [匹配规则与目录核查](Documentation/Matching.md)。正常照片会自动读取并填入焦距、光圈及已记录的对焦距离；缺少 FNumber 但存在拍摄 ApertureValue 时也会自动恢复；Canon 仅记录距离区间时保留并显示区间，不冒充单一实测距离；只有确实缺失的信息才需补全，光圈未知不启用暗角补偿。本地 CR2、NEF、CR3 自动读取回归及 NEF 实际界面填值已验证。这些改进从 0.2.0 候选包起纳入，当前 0.2.2 继续包含；既有发布资产保持原样。实际保存/重开范围见下文，不能推广至全部 RAW。

已验证真实 Canon 40D CR2、Nikon D70 NEF 的独立匹配，以及 Canon EOS R50 V / RF-S14–30mm CR3 的原生优先界面。当前 23 个常规测试组通过；全尺寸组默认明确跳过，已另以 `LENS_FULL_RENDER_TEST=1` 显式执行通过。既有 192 组原生渲染组合覆盖三项开关、部分及超完整强度、线性与 sRGB 传递，以及密集、几何网格、暗角网格、网格加残差四种布局。残差布局另与同设置的密集渲染配对比较；八种 EXIF 方向的工作映射路径与密集路径逐坐标比较通过。0.2.3 另补 288 个几何边界、8 个全画布增益、48 个裁切区域一致性、288 个约束裁切及 48 个缩放偏移检查。真实 A6000 校准映射的 6000×4000 专项还检查了三组未裁切强度及一组约束裁切，使用不透明常量源验证 alpha，不能当作照片 RGB 或光学准确率。这些是实现回归，不能替代实拍光学校准。本机安装程序已实际完成安装、启动和菜单检查，原厂关键文件哈希不变。

另新增两份完整公开 LX3 RAW（1:1、4:3）的自动模式、焦距/光圈、原生优先及实际解码预览核查；十八组测试通过。照片不进入源码包，仍未补齐宿主保存/重开或光学验收。

0.2.1 另以完整 Sony A6000、Olympus E-M5、Sony A200 RAW 对照公开 Exiv2 记录，三份均自动填入拍摄焦距和光圈，E-M5 的已记录对焦距离也自动填入。A6000/E-M5 自动生成对应配置；A200 镜头仍无法唯一匹配，单列为覆盖缺口。已排除 Sony 根据对焦位置推算的 Composite 距离，保留直接记录的距离与明确远距回退；十九组测试、96 个原生渲染组合通过，详见 `Evidence/public-capture-metadata-verification.json`。既有 0.2.0 候选包保持原样。

实际 A6000 RAW 已完成自动填值、校正应用、首次保存、关闭和重开，原 RAW 字节与三项选择保留。0.2.1 修复了宿主重算白平衡派生坐标时的浮点舍入误判；原片、主白平衡参数、尺寸及颜色空间仍严格校验，见 `Evidence/a6000-reopen-verification.json`。

0.2.2 将同一 2400 万像素测试 PXD 从 1,374,741,605 字节缩至 97,602,164 字节（约减少 92.9%），并完成新文档保存、关闭、重开和同配置 16 位 Display P3 PNG 导出比较。原 RAW 的 25,624,576 字节及 SHA256 不变；渲染并非逐像素相等：平均绝对通道差为 0.7201 / 65535，99% 不超过 15 / 65535，最大 209 / 65535。几何字段每个坐标误差检查不超过 0.001 px，暗角增益字段误差不超过 0.00001；增益网格的存储编码本身逐位无损。单独配置生成基准约 10.1 秒、进程峰值内存约 2.27 GB，**不是完整界面应用耗时或低内存 Mac 的性能保证**。迁移旧大文档仍有编码和历史开销。见 `Evidence/compact-map-verification.json`；所有 RAW、长期性能、无损渲染或光学等效验收仍未完成。

详见 [验收与限制](Documentation/Validation.md)、[兼容接口](Documentation/Compatibility.md) 和 `Evidence/`。历史证据记录对应当时构建，不要把旧 SHA256 当成当前包；当前包清单在 `Distribution/`。

## 源码结构与构建

- `Sources/Native/`：匹配、渲染、RAW 资源桥接、源绑定、推荐、原生面板与效果保存。
- `Sources/Installer/`：不依赖 Python 的 macOS 安装/启动程序。
- `Compatibility/`：已验证 Pixelmator 版本、关键文件哈希与部署契约。
- `Resources/`：效果模板、镜头数据库、ExifTool 源码运行资源。
- `Vendor/`：独立动态库、版权许可、对应上游源码和构建来源。
- `Tests/`、`Evidence/`：维护中的测试与精简验证结果。无原片、PXD 或临时缓存。
- `Scripts/`：源码构建、测试、DMG 打包。生成物在 `Build/` 和 `Distribution/`，不进入源码提交。

开发需 Apple 芯片 Mac、Xcode 命令行工具和 Python 3；**用户运行不需要 Python 或 Lightroom**。

```sh
python3 Scripts/build.py
python3 Scripts/test.py
# 可选的全尺寸专项需要 Tests/PrivateRAW/ILCE-6000.ARW 与固定校验和一致：
LENS_FULL_RENDER_TEST=1 Build/Tests/verify-full-resolution-boundaries
python3 Tests/verify-installer-installation.py
python3 Tests/verify-platform-contract.py
python3 Scripts/audit_catalog.py --run
python3 -m pip install -r Scripts/dmg_requirements.txt
python3 Scripts/package.py
python3 Scripts/verify_dmg.py
```

版本由 `Version.json` 统一管理。打包产物位于 `Distribution/<版本>-preview/`，已有同名资产会被拒绝覆盖；安装程序核对宿主版本、模块登记哈希与实际模块字节，旧版会提示保留文档后重新安装，不自动替换宿主。

原生渲染测试需本机兼容 Pixelmator 的 PTFoundation；它不会被复制进仓库。实际 RAW 专项可在本地 `Tests/PrivateRAW/` 放置 `Canon40D.CR2`、`NikonD70.NEF`、`CanonR50V.CR3`；这些文件被 Git 忽略，默认测试不会凭空生成真实 RAW 证据。依赖源码归档有 SHA256 清单，见 `Vendor/Sources/upstream-manifest.json`。

## 卸载与数据保留

退出预览宿主后，将 `LensDock.app` 和 `~/Applications/Pixelmator LensDock Preview.app` 移到废纸篓即可。PXD、原片、原厂应用和 Lightroom 目录不属于卸载内容。先保留含自定义效果的文档和兼容宿主；原厂应用无法提供同一个自定义滤镜。

本项目不传输照片或运行遥测。RAW 原始资源读取到独立临时目录用于元数据/支持检测后清理；保存的效果含标定、设置与检测预览，以便编辑和核验。预览版仍需更多照片、低内存设备及长期性能验证。
